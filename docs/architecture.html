Encore Commons · systems overview

Group venue planning with server-side taste grounding

One bounded agent turns pseudonymous favourites and a user-entered show location into a ranked shortlist with per-person evidence. Provider credentials never leave the server routes.

Built and exercised: every node above exists in this repository and is covered by the test suite or the live smoke test — the client flow, the route handlers, the agent state machine, both adapters, the session store and both provider calls.

Planned, not yet published: the hosted deployment. The target is Sites (Vinext on Cloudflare Workers) with runtime secrets, because the hosted app cannot read a local env file. Configuration and the public-demo checklist are prepared; no site has been deployed.

Not part of the system: booking, payments, routes and travel time. Distance is straight-line between coordinates. Provider hours, price, access and availability are unverified metadata and must be confirmed with the venue. Affinity is cultural fit, not a promise of enjoyment.
